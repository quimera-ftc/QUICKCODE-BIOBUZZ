# QUIAJUDA

---

## Sobre o projeto:

Este repositório contém dois modos autônomos desenvolvidos para a FTC, com o objetivo de demonstrar uma maneira facil e receptiva para equipes rookies e que ainda nao tem um equipamento adequado para criação de autonomos.

No TeamCode vc encontrara:

* AutoEsquerda: que faz o robo andar para a esquerda o equivalente a 1 tatame da arena
* AutoDireita: que faz o robo andar para a direita o equivalente a 1 tatame da arena


## Objetivo

O objetivo do nosso projeto é ajudar novos programadores e novas equipes a criarem uma base logica, pratica e acessivel para ter uma melhor curva de aprendizado na produção do software por tras de um robo de FTC, utilizando nosso projeto como um pontapé inicial pra desenvolver uma logica, onde no futuro sera valiosa quando o programador estiver trabalhando com uma biblioteca autonoma
